## Noxa 4.0.2

### Fixed

- **Quality dropping to 480p while the connection is fine.** When a video has to be converted and the server cannot convert it fast enough (slow processor, no graphics card), the stutters were taken for a slow connection: the quality went down step by step to 480p, and stayed low for the next titles. The server now sends the conversion speed with each progress update, so the Android TV app and the web player can tell the two apart. A conversion that is too slow lowers only the current title, to 720p at most, and the connection measurement stays valid for the next ones.
- **More accurate speed test.** The first megabyte of the speed test is no longer counted (the connection is still ramping up), so fast connections are no longer underestimated and high-bitrate files are no longer converted for nothing.
- **Android TV: tabs off screen.** With many libraries (administrator accounts), the top bar now scrolls and keeps the selected tab visible, instead of pushing *Settings* off the screen.
- **⋯ menu cut off.** The menu is now always shown above the page and fitted to the window. When it is taller than the screen, a fade shows that more options are below, so the administration options (Identify…, Refresh metadata, Archive…, Always keep on disk) no longer look missing.
