## Nexis 4.0: the first stable release 🎉

Nexis is a self-hosted media server for the movies, shows, anime, photos and audiobooks you already have: Python standard library + ffmpeg, no external account, no subscription, designed to run on a small machine without a graphics card.

After many 3.x releases, 4.0 is the first version declared **stable**. From now on releases follow semantic versioning, the *Stable* update channel only gets validated versions, and a *Test* channel lets you try what is coming.

### Highlights

- **Smart playback:** direct play, remux or transcode chosen per device, automatic quality, hardware transcoding (NVENC, VAAPI), HDR → SDR tone mapping, ASS / PGS subtitles rendered in the browser, Skip intro / Skip recap from chapters or audio fingerprints.
- **Every screen:** installable web app, native apps for Windows, macOS, Linux, Android and Android TV served by your own server, offline downloads with background transfer and resume, push notifications (no third-party service at all in the Android app), Chromecast, AirPlay and DLNA.
- **For the whole household:** profiles with PIN, 2FA, age ratings, screen time and bedtime, a kids interface, watch together, phone as a remote.
- **Linked servers:** pair several Nexis servers over their own encrypted link: shared accounts, merged libraries, best copy chosen automatically, administration of every server from one.
- **Cold storage:** archive titles to a disk, NAS, SFTP, WebDAV, S3, rclone or a linked server, optionally compressed to HEVC, and free up the library disks automatically with Radarr / Sonarr.
- **Beyond video:** photo library (albums, timeline, map, shared albums), audiobooks, live TV (M3U / XMLTV).
- **Make it yours:** six interface layouts, themes and a community theme store, custom home rows, English and French interface.
- **Peace of mind:** automatic backups (local, linked servers, S3, Google Drive, OneDrive, encrypted), alerts pushed to admins, updates from the interface.

### Install or update

- **Proxmox:** `bash -c "$(curl -fsSL https://raw.githubusercontent.com/xenix13/Nexis/main/deploy/proxmox-lxc.sh)"`
- **Debian / Ubuntu:** `curl -fsSL https://raw.githubusercontent.com/xenix13/Nexis/main/deploy/install.sh | bash`
- **Docker:** `ghcr.io/xenix13/nexis:4.0.0` or `:latest`
- **Package:** `nexis_4.0.0_all.deb` below.
- **Existing servers:** *Settings → Maintenance → Update*. Nothing to migrate: your data and settings are kept.
