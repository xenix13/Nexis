## Noxa 4.0.1

### Fixed

- **Apps not offered right after a release.** The apps (Windows, macOS, Linux, Android, Android TV) are attached to a GitHub release about fifteen minutes after it is created. A server that updated during that window found no apps and did not look again for 6 hours, so the Android app was not offered its update. The server now offers the apps of the latest release that has them and checks again every 10 minutes until its own release is complete.
